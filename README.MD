# 银河证券 星耀数智 AmazingData SDK 安装指南

## tgw 安装
```bash
pip install tgw-1.7.1-py3-none-any.whl
```
## AmazingData 安装
选择对应的python 版本, 比如你本地python是3.12，选择cp312这个whl文件
```bash
pip install AmazingData-1.0.0-cp312-none-any.whl
```
